EXPRESSION LAB - CHAY LOCAL, KHONG CAN DOCKER

Can Node.js co npm, Python 3.11, MongoDB Server local hoac URI Atlas.

CAI MOT LAN (tu thu muc goc):
  cd backend
  npm install
  npm run setup
  Mo .env o thu muc goc va kiem tra MONGO_URI.

TERMINAL BACKEND (tu thu muc goc):
  cd backend
  npm run dev

TERMINAL FRONTEND (tu thu muc goc):
  cd frontend
  npm install
  npm start

Mo http://127.0.0.1:5173
API: http://127.0.0.1:8010/docs
Nhan Ctrl+C trong moi terminal de dung.

TRAIN (trong backend, moi duong dan tinh tu thu muc goc):
  npm run setup:ai
  npm run data:prepare -- data/fer2013.csv --output data/datasets/fer2013
  npm run data:audit -- data/datasets/fer2013 --output data/fer2013-audit.json
  npm run train -- --dataset data/datasets/fer2013 --model mobilenet_v3_small --output ai/runs/mobile-v1 --epochs 30 --batch-size 16
  npm run evaluate -- --dataset data/datasets/fer2013 --model ai/runs/mobile-v1/model.pt --output ai/runs/mobile-v1/test.json

Dataset da co train/val/test dung 7 nhan thi bo buoc data:prepare.
Lan train tiep theo doi output thanh mobile-v2..., khong ghi de run cu.
Chi can setup:ai khi train hoac dung model TorchScript custom.
